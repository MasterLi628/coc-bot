# 部落冲突挂机

在雷电模拟器 9 上自动玩部落冲突（Clash of Clans）的脚本：用 ADB 截图，靠图像识别找按钮和建筑，带一个控制面板。

## 能做什么

- **收资源**：金矿、圣水收集器的气泡（仓库满了就不点）
- **自动升级**：读工人菜单的价格，先升最便宜的（也可以按优先级）；大本营优先；能造新建筑时先造
- **实验室**：优先研究最常用的兵种
- **自动进攻**：按几套配兵轮流试，按战果自动选最好的一套；找战利品多的对手、按方向下兵、抢光就提前结束
- **防掉线**：自动重新载入、账号被挤下线时停止并提醒
- **绝不花宝石**，不用研究药水、建筑之锤这类道具

## 怎么用

平时直接用打包好的软件：双击 `dist\部落冲突挂机\部落冲突挂机.exe`，在控制面板点"启动挂机"。

模拟器分辨率必须是 **1600×900**。详细说明见 [docs/使用说明.md](docs/使用说明.md)。

## 从源码运行 / 打包

```
pip install -r requirements.txt
python app.py          # 控制面板
python app.py --bot    # 直接挂机
python build.py        # 打包到 dist\部落冲突挂机\（或双击 打包.bat）
```

## 目录

```
app.py          程序入口
build.py        打包脚本
cocbot\         代码（主循环、升级、实验室、进攻、战果统计、控制面板……）
templates\      识别用的图片模板（按 1600×900 截的）
assets\         软件图标和界面图标（python assets/make_assets.py 重新生成）
docs\           使用说明
dist\           打包好的软件（不进 git）
```
