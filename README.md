# 部落冲突挂机

在 Windows 上通过雷电模拟器 9 和 ADB 自动操作《部落冲突》。脚本使用截图和图像模板识别游戏画面，控制面板负责启动、停止、设置和查看日志。

## 快速开始

1. 启动雷电模拟器 9，将分辨率设置为 **1600 × 900**，打开游戏并进入村庄。
2. 双击 `dist\部落冲突挂机\部落冲突挂机.exe`，在设置页检查 ADB 路径和模拟器连接。
3. 点击「启动挂机」；需要手动操作游戏时，先点击「停止挂机」。

软件版无需安装 Python。模拟器可以最小化，但电脑睡眠会中断运行。源码版和软件版共用挂机锁，避免同时控制模拟器。

## 功能

- 控制面板可配置 PushPlus 微信通知，接收进攻结果、升级研究和异常提醒；默认关闭，Token 仅保存在本机 `config.json`。
- 应用窗口、任务栏和启动图标更新为原创野蛮人主题。

- 收集资源，建造和升级建筑；支持大本营优先、升级顺序和保留工人等设置。
- 自动进行实验室研究，补充兵种和雷电法术；活动期间可领取符合条件的免费援军。
- 根据金币、圣水和暗黑重油门槛选择多人对手，按战果调整配兵并自动下兵。识别到雷电法术时优先攻击迫击炮或其他已识别的防御；没有可靠目标时攻击阵型核心区域。实际命中和摧毁情况仍需观察。
- 资源满时可开启普通多人练兵：每轮最多三次，之后休息一小时；连续三场摧毁率低于 30% 时休息四小时。练兵成绩与抢资源战绩分别记录。
- 建筑大师基地可定时收集可识别的资源、尝试升级已识别的训练营或星空实验室，并进行一场进攻，每小时最多尝试一次。升级前会核对建筑、资源和价格；目前仅适配单一狂暴野蛮人配兵，其他部队跳过进攻。
- 多人进攻支持横向滚动识别兵种栏；练兵会按实际可用兵种选择配兵。战利品统计会排除已满仓资源，并将无法确认的战果留空。
- 尝试从异常界面恢复；账号被挤下线时停止挂机。程序对宝石和道具操作设有保护。

当前代码包含 10 套配兵：均衡、哥布林多、巨人多、弓箭手多、亡灵、气球、法师、戈仑图腾、骷髅巨人和戈仑骷髅。可用兵种取决于游戏解锁和活动状态，缺少兵种时会尝试换用其他方案。抢资源按战利品比例评估；多人练兵按星数和摧毁率评估，两者使用独立记录。

图像识别依赖当前游戏界面、模板和分辨率；游戏更新后可能需要重新适配。雷电法术会优先攻击已识别的防御目标，目标识别失败时使用阵型核心区域作为兜底；实际命中和摧毁情况仍需观察。详细操作可参考 [使用说明](docs/使用说明.md)，以本 README 和当前代码为准。

## 源码运行和打包

在项目目录安装 Python 依赖后运行：

```powershell
pip install -r requirements.txt
python app.py          # 打开控制面板
python app.py --bot    # 直接运行挂机
python build.py        # 打包到 dist\部落冲突挂机\
```

也可以双击 `打包.bat`。打包会替换软件目录中的程序、模板和资源，并复制使用说明；已有设置、日志和战绩会保留。运行中的程序应先停止并关闭后再打包。

## 数据和排查

源码版将以下文件保存在项目根目录；打包版保存在 `dist\部落冲突挂机\`，两边的数据独立：

| 文件或目录 | 内容 |
| --- | --- |
| `config.json` | 控制面板设置 |
| `bot.log`、`bot.old.log` | 运行日志及上一份轮转日志 |
| `battles.csv` | 抢资源战绩 |
| `multiplayer_practice.csv` | 多人练兵的配兵、星数和摧毁率 |
| `multiplayer_practice_state.json` | 多人练兵次数和休息状态，重启后保留 |
| `builder_base_state.json` | 建筑大师基地上次尝试时间 |
| `practice.csv` | 单人练兵记录 |
| `debug\` | 识别失败等情况保存的截图 |

出现异常时先查看对应版本的 `bot.log` 和 `debug\` 截图。设置修改后，停止并重新启动挂机使其生效。

## 项目结构

- `app.py`：程序入口；`build.py`：打包脚本。
- `cocbot/`：挂机主循环、进攻、练兵、升级、实验室、ADB 和控制面板。
- `templates/`：图像识别模板；`assets/`：界面资源。
- `tests/`：自动化测试；`docs/`：使用说明。

运行测试：`python -m unittest discover -s tests -v`。
