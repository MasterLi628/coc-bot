# 部落冲突挂机脚本 使用说明

## 一、怎么启动 / 停止

**软件版**（平时用这个）：`coc-bot\dist\部落冲突挂机\` 文件夹就是整个软件，桌面上有快捷方式“部落冲突挂机”。这个文件夹可以整个拷到别的电脑上用，**不用装 Python**。设置（config.json）和日志（bot.log）也存在这个文件夹里。

1. 打开**雷电模拟器 9**，进入部落冲突，停在**村庄主界面**
2. 双击 **`部落冲突挂机.exe`**（或桌面快捷方式），打开控制面板，点右上角绿色的 **▶ 启动挂机**
3. **想停：点同一个位置的 ■ 停止挂机**

控制面板：
- **顶部状态栏**（每页都有）：运行中 / 已停止、已经运行了多久、最新一条日志，右边是启动/停止按钮
- **总览**：今日战果（进攻场数、抢到的金币和圣水、平均抢到对手的比例）、每套配兵的成绩条（★ 是目前最好的那套）、最近动态（升级、研究、进攻、需要注意的事）
- **运行日志**：实时日志（报错标红、警告标橙、做成的事标绿），可以切换"只看重要的"，也可以搜索
- **设置**：模拟器、功能开关、进攻门槛、升级规则等（见第五节）
- 左下角可以切换**浅色 / 深色 / 跟随系统**
- 每场战斗都记在软件文件夹的 `battles.csv` 里，可以用 Excel 打开
- 挂机在**后台运行**，没有黑窗口；面板可以**最小化**
- 点右上角 **✕** 会问：**退到后台**（面板缩到屏幕右下角托盘，挂机照常跑）还是**关闭脚本**（停止挂机并关掉软件）。勾"记住我的选择"以后就不再问，想改回来在设置页"点面板右上角 ✕ 时"里改
- 托盘图标是金币，中间绿点＝运行中，灰点＝已停止。**双击图标**打开面板；**右键图标**可以启动、停止、退出
- 右键"退出控制面板"时会问：停止挂机一起关，还是只关面板、让挂机在后台继续跑
- 控制面板只能开一个，已经开着时再双击会提示去托盘里找
- 不会重复启动：已经有挂机在跑时，再启动会被拦下
- 源码版（`python app.py`）还能用，跟软件版是同一套功能，两边不会同时挂机

注意：
- 运行期间**不要手动操作模拟器**，两边一起点会乱。想自己玩时先点"停止挂机"
- 模拟器可以最小化、可以被其他窗口挡住，不影响
- **手机和模拟器不能同时登录同一个账号**，手机一登录，模拟器就会掉线，**挂机会自动停止**（托盘会弹提示）。在模拟器里重新登录后，到控制面板点"启动挂机"
- 关显示器、锁屏（Win+L）都不影响挂机，但**电脑睡眠会停**。挂一整晚记得把 Windows 的“睡眠”设为“从不”
- 模拟器没开时脚本不会退出，会每 60 秒检查一次，模拟器打开后自动继续

## 二、脚本每一轮做什么

1. **安全检查**：有“工人都很忙”“缺少宝石”等可能花宝石的窗口，先关掉
2. **回到主界面**：不在村庄时尝试点“回营 / 领取奖励 / 继续”、关活动广告；连续 3 轮回不来就**重启游戏**
3. **保持活跃**：每轮在地图右边的空草地上来回拖一下（不用点击，免得点到带委托气泡的村民），防止仓库满了以后长时间没操作被游戏踢下线
4. **收资源**：点掉所有金币、圣水收集图标
5. **升大本营**（大本营优先模式）：钱够就升；钱不够就攒金币，只花圣水（金币存满了就不攒了）。如果弹出"升级尚未解锁，请先建造……"，说明要先造齐新建筑，这时会**花金币先造新建筑**。如果游戏弹出"在您升级之前……建议先进行一些进攻方面的升级"，就**听游戏的**：点取消，接下来 6 小时把训练营、兵营、部落城堡、实验室排到最前面先升，**这 6 小时里金币不再攒着升本，拿去升防御**；6 小时后再试升本
6. **造新建筑**：把右下角「建造」按钮划出的「建筑和英雄」列表翻到底，带绿色“新”字、买得起或免费的（城墙、圣水收集器、弹簧、炸弹等；升本送的免费城墙也会造）都造上，放在游戏自动选的位置；那个位置被挡住时，会从原地开始一格一格往外挪，每挪一格就看一次能不能放下。城墙、陷阱这类一次有好几个的会接着放
7. **升级建筑**：有空闲工人就把「建筑和英雄」列表从头到尾翻一遍，按**升级规则**挑一个买得起的升，一直升到没工人或没钱。规则有两种（设置页选）：
   - **均衡**（新装的默认）：先升最便宜的，同一种建筑等级越低越便宜，所以 1 级的会先补上来
   - **按优先级列表**：越靠上越先升。推荐把防御建筑排在前面、城墙放在防御后面，配合"城墙只在金币存满时才升"，城墙就成了金币满了以后的去处，不会和防御抢金币
   - 帆船、建筑工人小屋永远不升。城墙的等级上限由游戏管：到了当前大本营的上限，列表里就不会再出现，脚本也就不会升
   - 注意：开着"大本营优先"时，金币没满会攒着升本、只花圣水，而防御建筑全是花金币的，这段时间防御升不了
8. **实验室研究**：实验室空着时（右下角 0/1 变成 1/1），**先研究军队里的主力兵**（按成绩最好那套配兵里的占比），同一档里便宜的先研究。只点绿色的、花圣水的"确认"，旁边灰色的"确认 战斗之锤"是道具，永远不点
9. **自动配兵**：准备了 7 套配兵，每场轮流试，记下每套抢到对手战利品的比例。每套试满 5 场后，80% 的时候用成绩最好的，20% 继续试别的。军队是免费的，重配不花钱
   - 老兵种 4 套：均衡 / 哥布林多 / 巨人多 / 弓箭手多（巨人、炸弹人、弓箭手、哥布林、野蛮人）
   - 新兵种 3 套：戈仑图腾 / 骷髅巨人 / 戈仑骷髅（女巫戈仑、骷髅巨人、图腾投手，可能是限时兵种）
   - 兵种编辑里的卡片按头像认，不按位置，所以兵种增减、换位置都不会配错。**只挑兵种配得齐的方案**：限时兵种下架了，用到它的方案就不选；配兵时发现缺兵，当场换一套
   - 兵种编辑里有彩色（已解锁）但认不出的卡，日志会写"发现新兵种"，截图存到 `debug\新兵种.png`，控制面板右下角弹提示。把截图给 Claude 补上就能用
   - **法术**：法术栏没满就补满（目前只解锁了雷电，2 格，免费、马上就好）
   - **部落援军**：没加部落，但"部落城堡蛋糕"活动期间援军是免费的，会自动选 3 个法师 + 3 个弓箭手；按钮不是"免费"（要花突袭奖章）时不碰
10. **下兵**（见第三节）：开口 → 肉盾 → 输出 → 国王 → 法术 → 剩下的兵（援军、奖励的兵、认不出的兵）。战利品抢光就提前结束战斗
11. **进攻抢资源**（见第三节）：看对手 → 看布局下兵 → 等结束 → 回营/领奖励/开宝箱。金币和圣水**都满了**才不打
12. 随机休息 20～60 秒，进入下一轮

## 三、进攻策略

**1. 看对手（挑肥的打）**
- 读左上角“可获得的战利品”的金币、圣水数字
- 金币、圣水各有一个门槛（默认都是 **40000**），**没存满**的资源里任意一种达到自己的门槛就打。比如金币满了，就只看圣水够不够
- 都不够就点“下一个”（每次几百金币），最多换 **20** 个，换满了就将就打

**2. 看布局（朝资源下兵）**
- 截图找对手的**金矿、圣水收集器、储金罐**，优先选离中心最远的（大多在城墙外，没人保护）
- 挑 2～3 个方向，彼此错开，朝着这些资源建筑下兵。野蛮人会先打离自己最近的建筑，一落地就在抢资源
- 一个资源建筑都没认出来时，随机选一边下。**目前的颜色判断经常认不出资源建筑，所以实际上大多是随机选边**（之后要换成建筑模板）

**3. 找能放兵的边缘**
- 从屏幕外沿着方向一步步往里试，兵种卡上的数字一变，说明放下了，这个位置就是红线外的地图边缘
- 用便宜的小兵试（野蛮人优先）；试探的卡用光了就换下一张有兵的卡接着试，不会拿空卡白点
- 碰到“不能在红线范围内派遣部队”就换方向
- 战斗画面上的按钮（下一个、结束战斗、复制阵型、自动战斗、举报）**永远不会点到**

**4. 认兵种栏**
- 按卡片边框找每张卡的位置（兵种、援军、英雄、法术分组之间间距不一样，不能按固定间隔算），再按头像认是什么兵
- 卡片变灰＝用完；虚线空格＝没有卡

**5. 下兵顺序**
- **开口**：有野蛮人又有肉盾时，主攻方向左右两侧各放 4 个野蛮人，先清外围，肉盾才会往里走
- **肉盾**：女巫戈仑 → 骷髅巨人 → 巨人，放在主攻点；炸弹人跟上炸墙
- **输出**：熔岩气球 → 图腾投手 → 弓箭手、野蛮人在主攻点撒开；哥布林、皇家幽灵分到各个资源方向
- **国王**最后放在主攻点（英雄放下后卡片不会变灰，只点一下）
- 一个人口的小兵是**按住拖着下**的，几十个一下就放完
- **雷电**打离主攻点最近的资源建筑；认不出资源建筑就留着不放（盲打会落在草地上，法术免费，不放也不亏）
- 最后把还有兵的卡（部落援军、奖励来的兵、认不出的兵）全部放到主攻点
- 一旦离开战斗画面立刻停手，不会在村庄里乱点

**6. 活动奖励（有活动时才会出现）**
- **战斗中途**弹出"选择一项奖励！"：固定选**最左边**那张（目前见到的都是一大群兵，比如南瓜野蛮人 ×69），选到的兵放到主攻点。不选的话倒计时完会自动选，常常是活动货币
- **赢了之后、结算之前**的三选一（金币 / 圣水 / 活动货币）：没满的资源优先拿金币、再圣水，卡上标"已满"的不拿，都满了拿活动货币

**7. 战果**
- 每场记进 `battles.csv`。抢到比例＝抢到的 ÷ 对手开打时的战利品
- 几乎没抢到（不到 5%）的场次，会把战斗中途的截图存到 `debug\没抢到的战斗.png`，方便查原因
- 注意：自己仓库满的时候结算拿不到资源，抢到比例会偏低（三星也可能记成 20% 几）

## 四、防花宝石规则（脚本永远不会主动花宝石）

- 价格是宝石图标、或者是红字（钱不够）的，都不点
- 确认按钮上必须是白字价格才点
- 商店里只点橙色箭头指着、而且不要宝石的那张卡（避开建筑工人小屋）
- 弹出任何宝石相关的窗口，立刻关掉，放弃这次操作
- **道具（研究浓汤等）不碰**，留给自己用

## 五、设置（控制面板的"设置"页）

改完点右下角 **保存设置**（点"启动挂机"时也会自动保存），设置存在同目录的 `config.json` 里。**挂机正在运行时改了设置，要先停止再启动才生效。**

| 设置 | 作用 |
|---|---|
| 雷电 adb.exe | 雷电模拟器安装目录里的 `adb.exe`。点"自动查找"一般能找到，找不到就点"浏览…"手动选 |
| 操作哪台 | 默认"自动"，用在线的那台模拟器。同时开好几个模拟器时才需要选 |
| 检测 | 列出在线的模拟器和分辨率，**必须是 1600x900**，不对会标红 |
| 自动进攻抢资源 | 关掉就只发育、不打人 |
| 大本营优先 | 钱够先升大本营，平时攒金币 |
| 每轮最少/最多等 | 每轮之间随机等多少秒 |
| 几轮回不到村庄就重启游戏 | 连续几轮不在主界面就重启游戏 |
| 对手金币至少多少才打 | 金币没存满时，对手的金币达到这个数就打 |
| 对手圣水至少多少才打 | 圣水没存满时，对手的圣水达到这个数就打。两种都不够就点"下一个" |
| 最多换几个对手 | 每次 50 金币，换满了就将就打 |
| 兵分几路 | 兵分几个方向下 |
| 实验室自动研究 | 实验室空着就研究最便宜的兵种；没东西可研究时每 30 分钟再看一次 |
| 点面板右上角 ✕ 时 | 每次都问 / 退到后台 / 关闭脚本 |
| 升级规则 | **均衡**（新装的默认）：先升最便宜的，等级低的建筑先升，城墙排最后；**按优先级列表**：越靠上越先升，同一档里便宜的先升 |
| 优先级列表 | 选中一项点"↑ 上移 / ↓ 下移"调整，"默认顺序"恢复。"其他"代表脚本还认不出名字的建筑（日志里显示成"升级：建筑"） |
| 城墙只在金币存满时才升 | 勾上：金币没满时不碰城墙；不勾：金币没满也会升城墙。**例外**：按优先级列表、并且城墙排在第一位时，城墙有金币就升，不受这一项和"大本营优先"攒金币的限制 |

### 微信通知（PushPlus）

在设置页的「微信通知」卡片中开启通知，填入 [PushPlus](https://www.pushplus.plus/) 账号的 Token，点击「测试推送」确认手机微信能收到消息，然后保存设置。Token 只保存在本机 `config.json`，默认关闭。脚本会推送启动、进攻结果、升级/研究、掉线或异常等重要事件；同类提醒 15 分钟内最多发送一次。测试按钮会立即向绑定的微信发送一条真实测试消息。

优先级列表的默认顺序：储金罐 → 圣水瓶 → 兵营 → 训练营 → 实验室 → 法术工厂 → 迫击炮 → 法师塔 → 防空火箭 → 箭塔 → 加农炮 → 隐形炸弹 → 隐形弹簧 → 金矿 → 圣水收集器 → 部落城堡 → 英雄殿堂 → 其他 → 城墙

推荐顺序（防御先升，城墙当金币满了以后的去处）：加农炮 → 隐形炸弹 → 隐形弹簧 → 箭塔 → 防空火箭 → 法师塔 → 迫击炮 → 城墙 → 储金罐 → 圣水瓶 → 兵营 → 训练营 → 实验室 → 金矿 → 圣水收集器 → ……

## 换电脑 / 换模拟器实例

**用软件版最简单**：把 `dist\部落冲突挂机\` 整个文件夹拷过去，装好雷电模拟器 9、改好分辨率（下面第 2 步），双击 `部落冲突挂机.exe`，在“设置”页点“自动查找”和“检测”就行。

用源码版的话：

1. 安装 **Python 3**（安装时勾选 **Add python.exe to PATH**），然后在 `coc-bot` 文件夹里运行 `pip install -r requirements.txt`
2. 安装 **雷电模拟器 9**，把分辨率改成 **1600×900**（雷电右侧 设置→性能设置→分辨率，DPI 240），改完重启模拟器。**新建的实例默认是 1280×720，一定要改**
3. 把整个 `coc-bot` 文件夹拷过去，在模拟器里装好游戏、登录账号
4. 在 `coc-bot` 文件夹里运行 `python app.py` 打开控制面板，在"设置"页点"自动查找"和"检测"确认没问题
5. 回到"运行"页点"启动挂机"

## 六、看日志

同目录的 **`bot.log`** 记录了每一步，带日期时间。超过 2MB（大约一个星期）会自动改名成 `bot.old.log` 并重新开一个，只保留上一份，不会越积越多。常见日志的意思：

| 日志 | 意思 | 要不要管 |
|---|---|---|
| 工人都在忙，跳过升级 | 正常 | 不用 |
| 金币还不够升大本营，先攒着 | 正常 | 不用 |
| 先把训练营、部落城堡、实验室、兵种研究升上去，6 小时后再试升大本营 | 游戏建议先升进攻，听游戏的 | 不用 |
| 金币和圣水都满了，这轮不进攻 | 正常，等工人花钱 | 不用 |
| 对手战利品 金币 X / 圣水 Y，太少，换下一个 | 正常，在挑对手 | 不用 |
| 已经换了 10 个，将就打 | 附近对手都比较穷 | 经常出现可以在设置里调低金币/圣水门槛 |
| 下兵方向：…；兵种：… | 正常，朝资源建筑下兵，后面是认出的兵种 | 兵种列表里少了自己有的兵就找 Claude |
| 没找到能放兵的位置 | 下兵失败 | **反复出现就找 Claude** |
| 军队按"XX"配好（N 人口）：… | 正常 | 不用 |
| "XX"要用的 XX 现在没有，改用"YY" | 限时兵种下架了，自动换了一套 | 不用 |
| 发现新兵种：兵种编辑里有 N 张卡片认不出来 | 出了新兵种，或者老兵种换了样子 | **把 `debug\新兵种.png` 给 Claude 补模板** |
| 法术配好：雷电法术 | 正常 | 不用 |
| 免费部落援军已选好 / 没选上 | 活动期间才有 | 一直"没选上"就找 Claude |
| 战斗中弹出三选一奖励，选了最左边那张 | 正常，活动期间 | 不用 |
| 战斗结束的三选一奖励：拿了金币/圣水/活动货币 | 正常，活动期间 | 不用 |
| 雷电法术放在 (x, y) / 留着不放 | 正常 | 不用 |
| 这场几乎没抢到，战斗中途的截图存在… | 下兵可能出了问题 | 经常出现就把截图给 Claude |
| 出现可能花宝石的窗口，放弃… | 保护生效，没花宝石 | 不用 |
| 没找到升级按钮，换下一项 | 偶尔正常 | 一直刷屏再管 |
| 升级：XX（价格 金币/圣水） | 正常，按升级规则挑中了要升的建筑 | 不用 |
| 还停在摆放模式，先取消 | 上一轮造建筑没放下去，自动取消了 | 偶尔出现不用管 |
| 实验室：现在没有能研究的兵种 | 正常（实验室等级不够或兵种都升满了） | 不用 |
| 实验室：已开始研究（X 圣水） | 正常 | 不用 |
| 实验室：有 N 个兵种能研究，但圣水不够 | 正常，等攒够圣水 | 不用 |

| 没找到大本营 / 大本营这轮没升成 | 大本营每升一级外观都会变，新等级还没有模板；或者有前置条件 | **一直出现就找 Claude**。出问题时的截图存在软件文件夹的 `debug\` 里 |

| 账号已掉线……挂机已自动停止 | 同一个账号在手机上登录，模拟器被挤下线 | 关掉手机上的游戏，在模拟器里重新登录，再在控制面板点"启动挂机" |

## 七、脚本做不到的（需要自己或找 Claude）

- **不会用宝石加速**（升大本营想快就自己点“立即完成”）
- 升本前置条件只会处理"请先建造新建筑"这一种；要是弹出别的条件，会截图存到 `debug\` 并跳过
- 看布局只认资源建筑，**不认防御塔**，不会绕开迫击炮、加农炮；资源建筑也经常认不出，下兵方向多半是随机的
- 雷电只会打资源建筑，认不出就不放，不会瞄准防御塔
- 配兵认得野蛮人、弓箭手、巨人、哥布林、炸弹人、图腾投手、女巫戈仑、皇家幽灵、熔岩气球、骷髅巨人，法术只认雷电。新兵种、新法术要补模板（会有"发现新兵种"提醒）
- 战斗中途的活动奖励固定选最左边那张，不看卡上写的是什么；奖励的兵不分兵种，全部放在主攻点
- 战斗栏最多看 10 张卡
- 国服安卓版打不开阵型链接，要在 iPhone 上打开链接保存阵型
- 新解锁的低级对手、圣诞装饰很多的村庄，资源建筑可能认不全，会退回随机选边
- **不会复制/应用阵型**
- 新建筑位置是游戏自动选的，阵型会乱，需要之后复制阵型重新摆

## 八、文件说明

| 文件 | 作用 |
|---|---|
| `dist\部落冲突挂机\` | **打包好的软件**，平时用这个（`config.json` 设置、`bot.log` 日志、`battles.csv` 战果、`debug\` 出错截图都在里面） |
| `打包.bat` / `build.py` | 改了代码后重新打包软件（只覆盖程序和模板，不动设置、日志和战果） |
| `app.py` | 程序入口：`python app.py` 打开控制面板，`python app.py --bot` 直接挂机 |
| `requirements.txt` | 源码版要装的 Python 库 |
| `cocbot\bot.py` | 主循环：收资源、升级、研究、进攻、掉线恢复 |
| `cocbot\upgrade.py` | 升级、建造新建筑、大本营、防宝石逻辑 |
| `cocbot\menu.py` | 读「建筑和英雄」侧栏（建筑名、价格、资源图标） |
| `cocbot\lab.py` | 实验室研究 |
| `cocbot\attack.py` | 进攻流程、配兵、下兵策略 |
| `cocbot\stats.py` | 战果统计、自动选配兵 |
| `cocbot\scout.py` | 读数字（对手战利品、价格） |
| `cocbot\pinch.py` | 双指缩小画面 |
| `cocbot\adbtool.py` | 截图和点击（用雷电自带的 adb） |
| `cocbot\panel.py` | 控制面板界面 |
| `cocbot\config.py` | 读写设置、自动查找雷电 |
| `templates\` | 识别用的图片模板，**不要删** |
| `bot.pid` | 正在运行的挂机进程号，用来停止和防止重复启动（在 `%LOCALAPPDATA%\coc-bot\` 里） |

> 模板是按 **1600×900 分辨率**截的，**不要改模拟器分辨率**，否则识别会失效。
